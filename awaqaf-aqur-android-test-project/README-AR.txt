نسخة أندرويد تجريبية - أوقاف عقر

ما الذي تفعله هذه النسخة؟
- تفتح موقع أوقاف عقر الحالي داخل تطبيق Android بسيط (WebView).
- تحافظ على الموقع كما هو؛ المحتوى يُحمّل من الإنترنت.
- هذه نسخة اختبار وليست إصدار متجر Google Play.

طريقة استخراج APK دون تثبيت Android Studio:
1) أنشئ مستودع GitHub جديداً أو استخدم مستودعاً تملكه.
2) ارفع محتويات هذا المجلد إلى جذر المستودع (وليس المجلد المضغوط نفسه).
3) افتح تبويب Actions في المستودع.
4) اختر "Build Awaqaf Aqur APK" ثم Run workflow، أو انتظر انتهاء البناء بعد رفع الملفات.
5) افتح نتيجة التشغيل الناجح، ثم Artifacts، وحمّل Awaqaf-Aqur-test-APK.
6) فك ضغط الملف الناتج على الكمبيوتر، وانقل app-debug.apk إلى هاتف Android وثبّته.
   قد يطلب الهاتف السماح بالتثبيت من هذا المصدر.

ملاحظات مهمة:
- التطبيق يحتاج اتصال إنترنت لأن الموقع يُحمّل من GitHub Pages.
- رابط الموقع المضبوط في MainActivity.kt هو:
  https://gwagonpro7-arch.github.io/awaqaf-aqur/
- إذا كان رابط النشر مختلفاً، عدّل homeUrl قبل البناء.
- لا تشارك ملف APK مع الجمهور؛ إنه توقيع debug للتجربة فقط.
- قبل النشر الرسمي يجب إعداد توقيع إصدار Release، ومراجعة الأمان والخصوصية،
  واختبار الوظائف الفعلية، وتحديث الأيقونة إلى شعارك الرسمي.
- هذه الحزمة مصدر مشروع Android؛ لم يتم بناء APK داخل هذه البيئة.
